# Claim 6 limitations and deviations

The official LMSYS dataset is gated in HF Jobs and its content hash is
redacted. The pinned `dim` mirror has the exact expected 33,000/32,980/20
cohort invariants and a recorded parquet/LFS SHA-256, but those facts do not
prove byte identity with the gated file. The author archive is HTTP 410, so
undocumented text preprocessing defaults cannot be matched.

The paper does not numerically define “near-zero.” The predeclared verifier
uses a scale-free threshold: median plugin width below half of debiased width
for every GARS.
